# RAG/LLMエンジニア 学習ロードマップ

## 目的

実験の前に仮説を立て、効率的にRAG/LLMチャットボットを最適化できるようになる。

---

## 全体構成

| Phase | 領域 | 優先度 | 目的 |
|-------|------|--------|------|
| 1 | 情報検索の基礎 | 最優先 | 理論的な判断力 |
| 2 | ベクトル空間と埋め込み | 最優先 | 理論的な判断力 |
| 3 | 統計と実験設計 | 最優先 | 理論的な判断力 |
| 4 | RAGアーキテクチャ | 高 | 設計の選択肢を増やす |
| 5 | LLMの基礎 | 中 | プロンプト設計の判断力 |
| 6 | 実務スキル | 高 | 実務での回転速度を上げる |
| 7 | 発展トピック | 低 | 興味駆動で随時 |

## 学習の進め方

### 原則

1. **実務の疑問から逆算する**
   - 「なぜこのパラメータ？」→ その背景だけ掘る
   - 体系的に学ぶより、必要なところをつまみ食い

2. **数式は「読める」レベルでOK**
   - 導出できる必要はない
   - 各項が何を意味するか説明できれば十分

3. **可視化を習慣にする**
   - スコア分布、埋め込みのt-SNE、Recall@kカーブ
   - 見れば仮説が浮かぶことが多い

4. **30分ルール**
   - 疑問が出たら30分だけ深掘り
   - それ以上は後日に回す

### 週次の学習時間目安

| Phase | 期間 | 週あたり時間 |
|-------|------|-------------|
| Phase 1-3 | 各2-3週間 | 3-5時間 |
| Phase 4 | 2-3週間 | 2-3時間 |
| Phase 5 | 1-2週間 | 2-3時間 |
| Phase 6 | 継続的 | 実務の中で |
| Phase 7 | 随時 | 興味に応じて |
